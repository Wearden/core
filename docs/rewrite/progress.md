## Agentless scan, hardening and rollback over SSH and WinRM (source only)

Each asset now has a connection: agent (installed agent, unchanged), ssh (Linux, or Windows with the OpenSSH server) or winrm (Windows). For ssh and winrm, POST /api/assets/{id}/agentless/setup signs in with the stored credential (SSH host key confirmed and pinned first), installs the reviewed agent stopped and not started at boot, and lets it enroll and deliver a first scan.
